# История версий SberAct

Одна строка на версию, новые — сверху. Версию поднимаем в `package.json` и
`electron-app/package.json` (одинаково) перед каждым релизом.

## 2.1.0 — 16.10.2026
- Шаблоны актов переехали в новое дерево `Templates\Банкротство`. Акт выбирается
  по осям дела (тип лица, заявитель, статус должника, залог, процедура) и роли
  из имени файла, а не по жёстким путям. Подключены «Включение в РТК» целиком
  и «Инициирование» для физлиц, включая самобанкротство и умершего должника.
- Отложение разделено на два акта: общее и с привлечением третьего лица —
  в интерфейсе подсписком под общей галкой.
- Значения из анализа приезжают в акт в правильном регистре: «ИВАНОВ ИВАН
  ИВАНОВИЧ» становится «Иванов Иван Иванович», то же для адресов и организаций.
- Дата заседания печатается словами: «02 октября 2026 года в 09 часов 05 минут».
- Скачанный акт больше не называется `document_<uuid>`: подпись лежит рядом
  с файлом и переживает перезапуск бэкенда.
- Если шаблона для выбранной галки в дереве нет, генерация не подставляет
  чужой акт, а пишет предупреждение «шаблон не готов».

## 2.0.1 — пересборка 06.08.2026
- Конвертер PDF больше не требует Microsoft Visual C++ Redistributable: рантайм
  (`msvcp140.dll` и соседи, x64) едет в установщике и раскладывается в
  `converter\pyruntime` и `torch\lib`. Раньше на машине без VC++ torch падал с
  `WinError 126`, и конвертация просто не запускалась.
- Установщик снимает зависший `SberAct.exe` до распаковки: запущенный отдельно
  бэкенд держал файл открытым, и на диск попадал недописанный PE — Windows
  встречала его как «Неподдерживаемое 16-разрядное приложение».
- После установки проверяется, что файл бэкенда на месте и не обрезан.
- Шрифт Roboto вшит в бандл вместо ссылки на `fonts.googleapis.com` — на
  офлайн-машине он не грузился вовсе.
- На флешке появилась «Проверить установку.cmd» с манифестом SHA-256: сверяет
  2233 файла установки и отвечает, цела ли она.

## 2.0.1 — пересборка 05.08.2026
- Суммы: поле больше не подхватывает значение соседнего 
- денежный захват
  ограничен корректным денежным токеном.
- Самобанкротство: общая сумма долга берётся из сводной фразы заявления, а не из строки первого кредитора;
  блок «Финансовые данные» больше не прячется — суммы можно править.
- Номер дела мирового участка («2-7-3490/2025», ссылка на судебный приказ) не
  выдаётся за номер арбитражного дела.
- Резолютивка ВКЛ в РТК: вернулось «в размере» перед суммой (13 шаблонов);
  пустая разбивка («основного долга в размере  руб.») вычищается.
- Интерфейс: чекбокс «Короткий текст» переехал в блок «3. Финальные СА»;
  из предпросмотра убран захардкоженный «Арбитражный суд города Москвы».
- Шаблоны ипотеки обновлены; врезке извещения возвращён автоподбор высоты.

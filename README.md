# SberAct Document Generator

Генератор судебных актов на основе заявлений для Astra Linux

## 📋 Описание

SberAct Document Generator - это десктопное приложение для автоматического анализа заявлений и генерации судебных актов. Приложение использует искусственный интеллект для извлечения данных из документов и создания структурированных судебных актов.

## 🎯 Основные возможности

- **Автоматический анализ заявлений** - извлечение ключевых данных с помощью AI/ML
- **Интеллектуальная классификация** - определение типа документа и подходящего шаблона
- **Генерация судебных актов** - создание документов на основе извлеченных данных
- **Поддержка РТК** - специализированные шаблоны для реестра требований кредиторов
- **Кроссплатформенность** - работает на Astra Linux и других Debian-based системах

## 🚀 Быстрый старт

### Системные требования

- **ОС**: Astra Linux 1.7+ или Ubuntu 20.04+
- **Python**: 3.10+
- **Node.js**: 18+
- **RAM**: 8 GB+
- **Диск**: 20 GB свободного места

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/sberact-document-generator.git
   cd sberact-document-generator
   ```

2. **Запустите установку**
   ```bash
   sudo bash install.sh
   ```

3. **Запустите приложение**
   ```bash
   bash start.sh
   ```

### Ручная установка

Если автоматическая установка не работает:

1. **Установите системные зависимости**
   ```bash
   sudo apt update
   sudo apt install -y python3 python3-pip python3-venv build-essential git curl
   ```

2. **Установите Node.js 18+**
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo bash -
   sudo apt install -y nodejs
   ```

3. **Установите npm зависимости**
   ```bash
   npm install
   cd electron-app && npm install && cd ..
   ```

4. **Настройте Python backend**
   ```bash
   cd python-backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python -m spacy download ru_core_news_sm
   deactivate
   cd ..
   ```

## 📖 Использование

### 1. Загрузка документа

- Перетащите Word документ (.docx) в область загрузки
- Или нажмите "Выбрать файл" для ручного выбора

### 2. Анализ документа

- Система автоматически проанализирует содержимое
- Извлечет ключевые данные (ФИО, даты, суммы, и т.д.)
- Покажет уровень уверенности в результатах

### 3. Выбор шаблона

- Система предложит подходящие типы судебных актов
- Выберите нужный шаблон или оставьте автоматический выбор

### 4. Генерация документа

- Проверьте извлеченные данные
- Нажмите "Сгенерировать документ"
- Скачайте готовый судебный акт


### Команды разработки

```bash
# Запуск в режиме разработки
npm run dev

# Сборка React приложения
cd electron-app && npm run build

# Сборка для Linux
npm run dist:linux

# Запуск только Python backend
cd python-backend && source venv/bin/activate && python app/main.py

# Запуск только React dev server
cd electron-app && npm start
```

### API Endpoints

- `GET /` - информация о сервисе
- `GET /health` - проверка состояния
- `POST /analyze-document` - анализ документа
- `GET /templates` - список шаблонов
- `POST /generate-document` - генерация документа
- `GET /download-document/{id}` - скачивание документа

## 🎨 Шаблоны документов

### РТК - Одно обязательство

Шаблон для судебного акта о включении в реестр требований кредиторов по одному обязательству.

**Поля:**
- ФИО заявителя (обязательно)
- Адрес заявителя (обязательно)
- Дата заявления (обязательно)
- Название суда (обязательно)
- Номер дела (обязательно)
- Сумма долга (обязательно)
- Кредитор (обязательно)
- Должник (обязательно)
- Номер договора (опционально)
- Дата договора (опционально)
- Тип обязательства (опционально)

### РТК - Несколько обязательств

Шаблон для судебного акта о включении в реестр требований кредиторов по нескольким обязательствам.

**Поля:**
- ФИО заявителя (обязательно)
- Адрес заявителя (обязательно)
- Дата заявления (обязательно)
- Название суда (обязательно)
- Номер дела (обязательно)
- Общая сумма долга (обязательно)
- Кредитор (обязательно)
- Должник (обязательно)
- Количество обязательств (опционально)

- **Пользователи**: Запускайте от имени непривилегированного пользователя

- **CORS**: Настройте разрешенные домены в продакшене

## 🐛 Устранение неполадок

### Частые проблемы

1. **Python backend не запускается**
   - Проверьте виртуальное окружение
   - Убедитесь, что порт 8000 свободен
   - Проверьте логи в консоли

2. **React dev server не запускается**
   - Проверьте порт 3000
   - Убедитесь, что зависимости установлены
   - Проверьте версию Node.js

3. **Ошибки анализа документов**
   - Проверьте модель spaCy
   - Убедитесь, что документ в формате .docx
   - Проверьте права доступа к файлам

### Логи

- **Electron**: Консоль разработчика (F12)
- **Python**: Консоль терминала
- **React**: Браузерная консоль

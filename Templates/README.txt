Папка шаблонов актов
====================

Положите эту папку "Templates" рядом с исполняемым файлом (exe) приложения — тогда все шаблоны будут находиться автоматически.

Структура групп (в каждой папке — соответствующие .docx):
- шаблоны актов без залогов — физ реструк/реализация, юр наблюдение, инициирование, конкурсное
- Залог — Наблюдение, Конкурсное, Реструктуризация, Реализация
- умерший
- КФХ
- Проект Никите/ипотека
- СУдебные акты физики/Взыскание — взыскание с ИП
- Взыскания ИП + Залог, Взыскание ИП залог авто
- Взыскание ЮЛ, ЮЛ взыскание залог, взыскание ЮЛ залог авто
- на 19.02

Скопируйте ваши .docx из прежних папок проекта в эти же пути внутри Templates.

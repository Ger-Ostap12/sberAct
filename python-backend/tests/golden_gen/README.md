# Golden-проверка генерации

Сценарий воспроизводит запрос из `useGenerateDocument.ts`: плоские поля,
обязательства, наследники, третьи лица, должники, предметы ипотеки, созаёмщики
и поручители. Для ипотечных документов в тестовом сценарии явно выбраны полное
удовлетворение иска и солидарность при нескольких должниках. Это настройки
фикстуры, а не автоматический выбор приложения за пользователя.

В текущем корпусе 69 документов. В 65 сценариях проверяется полный текст актов.
Четыре сценария инициирования относятся к веткам без шаблонов;
`unavailable_cases.json` описывает эти ограничения. Для них проверяются код
`templates_unavailable` и список недоступных актов. Эти тесты не пропускаются.
Неожиданный отказ в другом сценарии считается ошибкой.

Проверка:

```powershell
.\python-backend\venv\Scripts\python.exe -m pytest python-backend/tests/golden_gen --require-golden-corpus -q
```

Дата генерации заморожена, идентификаторы выходных файлов в эталон не входят.
Выходные документы создаются во временном каталоге.

После намеренного изменения маршрутов или текста сначала изучите различия
и регрессионные проверки. Только затем обновляйте эталон:

```powershell
.\python-backend\venv\Scripts\python.exe python-backend/tests/golden_gen/regenerate_gen_golden.py
```

Команда не записывает эталон при исключениях и неподтверждённых отказах.
При появлении шаблонов ранее недоступной ветки нужно пересмотреть её запись
в реестре и ожидаемый результат.
